# Which model when

The model is not the point. The result is.

The best model is the one you actually use.

A prompt with no model and good thinking beats a perfect framework with vague intent.

---

## The quick answer

| Model | Best for | Skip it when |
|---|---|---|
| **FIXIT** | Everyday writing where format and tone matter — product descriptions, emails, social posts, summaries | The task is about a specific audience, not a specific format |
| **CO-STAR** | External communication where the reader is the key variable — campaigns, landing pages, newsletters, customer emails | The task has no specific audience or the format matters more than who reads it |
| **RISEN** | Structured deliverables where the process matters — plans, analyses, reports, step-by-step guides | The task is a piece of writing, not a structured work result |
| **No model** | Quick questions, brainstorming, simple rewrites, anything where casual conversation with AI is enough | You need consistent output across multiple texts or the result really matters |

---

## Three questions that point you to the right model

**1. Is the output a structured deliverable — a plan, an analysis, a guide?**
Yes → RISEN.
No → keep going.

**2. Does the audience change how the text should be written?**
Yes → CO-STAR.
No → keep going.

**3. Does the format or tone need to be precise?**
Yes → FIXIT.
No → no model needed. Write naturally.

---

## When none of them fit

Most of your daily AI use does not need a model. A quick question, a brainstorm, a rough draft to react to — casual prompts work fine for all of that. The models exist for the tasks where getting it right matters and casual is not enough.

If you are not sure which model to use, start without one. If the output is not what you wanted, look at what was missing and pick the model that covers it.

---

## A note on combining models

Nothing stops you from mixing elements across models. Some people add a Narrowing constraint (from RISEN) to a FIXIT prompt. Others borrow the Audience element (from CO-STAR) when writing a FIXIT prompt for an external text.

The models are not competing systems. They are overlapping checklists. Use whatever combination gives you the output you need.

---

## The one thing that matters more than any model

A model is a tool for thinking clearly. It is not a substitute for thinking.

If you know what you want, who it is for, and what good looks like, you will get a strong result with or without a model. If you do not know what you want, no framework will save you.

The best prompt is a clear thought. Everything else is just structure around it.
